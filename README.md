# Tanish Kagathara - Interactive Retro Portfolio 👾

Welcome to the source code of my personal portfolio! This is a stylized, 8-bit retro-themed website designed to showcase my experience and projects as a Full Stack Developer. It features a fully interactive command-line terminal and nostalgic web design elements to create a unique and engaging user experience.

## ✨ Features

- **Interactive Retro Terminal:** Type commands directly into the built-in terminal! Supported commands include:
  - `help` - Lists all available commands
  - `about` - Displays a brief biography
  - `skills` - Shows skill levels and technical metrics
  - `experience` - Details professional history
  - `projects` - Lists featured projects
  - `contact` - Displays contact information
  - `music` - Toggles the retro background music
  - `snake` - Play a fully functional hidden Snake minigame!
  - `clear` - Clears the terminal screen
- **Responsive Layout:** Works smoothly on desktop and mobile devices.
- **Dynamic Project Modals:** Detailed views of featured projects including technical stacks and live links.
- **8-Bit Aesthetic:** Custom CSS styling including pixel fonts, scanline overlays, CRT flicker effects, and custom animated scrollbars.

## 🛠️ Technology Stack

This portfolio is built using core web technologies without any heavy frameworks to ensure maximum performance and precise control over the retro aesthetic:
- **HTML5:** Semantic structure and layout.
- **CSS3:** Custom styling, CSS Variables, Flexbox/Grid, and complex keyframe animations for the CRT and pixel effects.
- **Vanilla JavaScript:** Powers the interactive terminal parser, DOM manipulation, event handling, and the logic for the Snake game.

## 🚀 Getting Started

Since this is a static website, getting it running locally is incredibly simple.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tanishkagathara7/Portfolio.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd Portfolio
   ```
3. **Run a local server:**
   You can use any local server (like VS Code Live Server, Python's `http.server`, or `npx http-server`).
   ```bash
   npx http-server .
   ```
4. **Open in Browser:**
   Visit `http://localhost:8080` to interact with the portfolio!
